Установка MovieList

Хаб скачает расширение, проверит подпись и подключит автоматические обновления. После этого его можно закрыть — дальше всё работает в фоне.

Расширение

Будет установлено в папку:

Подключите папку в Chrome

Chrome не разрешает программам самим добавлять распакованные расширения, поэтому этот шаг нужен один раз.

  1. Откройте страницу расширений Chrome.
  2. Включите «Режим разработчика» в правом верхнем углу.
  3. Нажмите «Загрузить распакованное расширение» и вставьте путь — он уже скопирован.
  4. Откройте MovieList один раз, чтобы он связался с хабом.
